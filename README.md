# カラオケ持ち歌

カラオケに行ったとき「この曲、上手く歌えるか？」をパッと出すための、自分だけの持ち歌帳（PWA）。

- 持ち歌を **歌える度★1〜5** とキーで管理。一覧を開けば★の高い順
- 曲名・アーティストで検索（ひらがな/カタカナ・長音・全角半角のゆれに強い）、タグ・曲調・機種で絞り込み
- iTunesの曲データから検索して登録、手入力もOK
- 「歌った！」で機械採点の点数を記録 → 最高点・推移グラフ
- おまかせ選曲、記録（よく歌う曲・最高点ランキング）
- Googleドライブにバックアップ／復元、CSV入出力、利用者の切り替え
- オフラインで動く（ホーム画面に追加して使う）

運用は [OPERATIONS.md](OPERATIONS.md)、要件は [docs/requirements.md](docs/requirements.md)。
